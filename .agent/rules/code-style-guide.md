# Code Style Guide

- Follow the **Airbnb Style Guide**.
- Use **PascalCase** for Svelte component filenames (e.g., `UserCard.svelte`) and standard SvelteKit routing conventions (e.g., `+page.svelte`).
- Components are defined in `.svelte` files.
- Prefer **TypeScript**, ES modules, arrow functions, and explicit types.
